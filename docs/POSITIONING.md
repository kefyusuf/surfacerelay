# Positioning

## One-line

**Expose stateful server-driven application actions to AI agents without duplicating business logic or creating agent-only APIs.**

## Developer version

SurfaceRelay separates action semantics from framework runtime bindings and agent surfaces, then routes invocations through the application's real validation, authorization, tenancy, confirmation, idempotency, and audit boundaries.

## Laravel version

Define a Laravel action once and safely bind it to Livewire/Filament pages, WebMCP browser agents, and later MCP clients while preserving the same application policies and trusted runtime state.

## What not to claim

- Not an MCP replacement.
- Not an official WebMCP project.
- Not a new browser standard.
- Not a universal agent protocol yet.
- Not automatic AI enablement for every backend method.
