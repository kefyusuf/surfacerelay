# SurfaceRelay 0.1.0-alpha.1

Published on 2026-10-06; both exact-version registry consumers are verified.

## Install the experimental alpha

```sh
composer require surfacerelay/laravel:0.1.0-alpha.1
npm install @surfacerelay/browser-runtime@0.1.0-alpha.1
```

Packages are public on [Packagist](https://packagist.org/packages/surfacerelay/laravel)
and [npm](https://www.npmjs.com/package/@surfacerelay/browser-runtime).
npm's `alpha` tag also points to this version. The first publication received
a `latest` alias despite `--tag alpha`; npm refused its removal with HTTP 400.
Both aliases point to this prerelease. Use its exact version or `@alpha`; do
not infer stable API support from the registry alias. The same first-publication
behavior is reported in [npm CLI issue 8490](https://github.com/npm/cli/issues/8490).

## Boundaries

Only Laravel and browser runtime are released. MCP/OpenAPI publication is outside
this alpha. APIs remain experimental; server authorization, tenant context,
confirmation, idempotency and output policy remain authoritative. See the
[changelog](../../CHANGELOG.md), [security policy](../../SECURITY.md) and
[compatibility guidance](../VERSIONING-COMPATIBILITY.md).

Source manifests/private builders remain unchanged. Readiness/preview tooling
retains conservative NO-GO and grants no publication authority. No production
guarantee, support SLA, stable API or general native-agent/WebMCP certification
is introduced. Receipt documentation commits do not change the frozen source.
