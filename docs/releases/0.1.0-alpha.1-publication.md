# SurfaceRelay 0.1.0-alpha.1 publication

Status: authorized, final verification in progress; no registry publication yet.

## Scope and authority

The owner authorized completion of the first two-package alpha on 2026-10-06:
`surfacerelay/laravel` through the approved distribution mirror/Packagist channel,
and `@surfacerelay/browser-runtime` through npm with public access and `alpha` tag.
Necessary reviewed integration, exact-source mirror updates and prerelease tags
are within this authorization. Stop on a blocking finding or changed scope.

Use interactive `kefyusuf` owner sessions with device 2FA and immediate identity/
authority rechecks. Unattended scoped-token/OIDC provisioning is deferred; no
granular token, CI publisher or 2FA bypass is claimed. Credentials are outside
repository/evidence/package contents. T-903's verified preparation is documented
in [the handoff](0.1.0-alpha.1-publication-handoff.md).

## Final package path

`scripts/alpha_publication_artifact.py` accepts both reverified private candidates
from one exact source revision and version. It prepares separate final trees,
replaces preview-only README text, uses the reviewed metadata transformation and
packs npm offline. It never writes a registry or grants publication approval.

The evidence records candidate archive hashes, source revision, final file
manifests and packed tarball hash. Runtime/license/migration bytes are preserved;
only the reviewed manifests and README differ. The Composer root has no version
field; the mirror's tag supplies its version. Private local builders and their
conservative NO-GO remain unchanged.

The public-browser verifier checks safe tar paths, archive hash, exact identity/
metadata/export contract and every file hash. Its installed verifier requires an
isolated real package copy with identical bytes. CI runs the existing import,
types, bundle, DriverRegistry and deep-import fixture behavior on that public copy.

## Final verification and receipt

Final source revision, archive/content hashes, exact-head CI, mirror commit/tag
mapping and registry receipts will be recorded after they are actually verified.
The initial preparation mirror/source is not the final release provenance.

Before writes: rebuild from the final merged revision, run canonical/guardrails,
strict Composer validation, public browser consumer and installed Laravel
application acceptance, and complete independent artifact review.

After writes: verify exact npm/Packagist versions and install from those registries
in fresh consumers; distinguish registry results from local artifact evidence.
No production-security guarantee, stable API, support SLA or general native-agent/
WebMCP certification is introduced by this experimental alpha.
