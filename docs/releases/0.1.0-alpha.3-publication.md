# Coordinated 0.1.0-alpha.3 publication

Published on 2026-10-08 with owner authorization and device authentication:
`@surfacerelay/browser-runtime@0.1.0-alpha.3` on npm and
`surfacerelay/laravel:v0.1.0-alpha.3` on Packagist.

```sh
npm install @surfacerelay/browser-runtime@0.1.0-alpha.3
composer require surfacerelay/laravel:0.1.0-alpha.3
```

npm `alpha` points to alpha.3; `latest` remains alpha.1. Install explicit versions.
Alpha.3 publishes T-910's opt-in `FilamentBrowserDriver`,
`FilamentSelectionCoordinator` and `GlobalFilamentSelectionRuntime` root exports.
Existing default Livewire behavior remains compatible. All 157 Laravel PHP/migration
files match alpha.2; the coordinated release does not change Laravel runtime behavior.
See the [consumer guide](../consumers/browser-runtime.md#opt-in-filament-selection-driver-since-010-alpha3).

## Actual registry acceptance

- A clean npm installation matches all 45 browser files and passes root import,
  Filament declarations/typecheck, Vite bundle, smoke and denied deep-import controls.
- A clean Packagist installation matches all 160 Laravel files and passes 11 HTTP,
  authorization and shared-store race tests with two workers. Deliberately disabling
  invocation authorization fails the oracle; restoring it passes all 11 tests.
- A Filament consumer installs both packages from their actual registries without
  path/local repositories. Laravel 13.35.0, Livewire 4.4.7 and Filament 5.10.0 pass
  23 HTTP and seven response-loss controls; installed files match the same manifests.
- Nine real Chrome WebMCP calls cover empty selection, selection drift after UI
  approval, execution/replay, edit approval, committed response loss, SQL inspection
  before explicit replay, and a stale list binding. SQL effects remain
  `0 -> 1 -> 2 -> 2`, targeting only selection102 and edit101. Response loss and stale
  invocation report `execution_failed` with unknown outcome; no automatic retry occurs.
- Required canonical validation passes, including 22 HTMX and 41 WebMCP fixtures.
  The earlier exact-source preparation also passed 195 Python and 508 browser tests;
  these are preparation results, not additional registry test counts.

## Limits and cleanup

Experimental, unofficial prerelease. Native checks use a simulated local ledger
and serial controls; they do not qualify real payments, production, performance,
SLA or general native interoperability. Helper exclusion does not cover ordinary
UI calls; deferred writes are not transactional. Inspect state after unknown outcomes.
MCP/OpenAPI packages remain outside this release and source metadata remains private.

The task-owned registry container, demos, cache, database, native tabs and release
staging are removed after proof is retained. Existing images/resources and user
Composer locks are preserved. No new image, named volume or worktree was created.
