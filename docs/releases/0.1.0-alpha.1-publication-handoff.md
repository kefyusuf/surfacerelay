## Composer channel decision

Public Packagist expects `composer.json` at the repository root. SurfaceRelay's
Laravel manifest lives at `packages/laravel/composer.json`; there is no root
manifest. Submitting the current monorepo URL does not solve this package path.
See [Packagist's requirements](https://packagist.org/about) and
[its monorepo explanation](https://blog.packagist.com/installing-composer-packages-from-monorepos/).

**Owner-approved approach:** retain this authoritative development monorepo and
use a distribution-only Laravel mirror whose root is the package root. Review
the mirror's owner/name, source-revision-to-mirror mapping, preserved license,
reproducible extraction and matching prerelease tag before creating it. Mirror
creation, pushes/tags and Packagist submission are separate authorized actions.
[ADR 0013](../adr/0013-laravel-distribution-mirror.md) clarifies how this preserves
[ADR 0008](../adr/0008-monorepo-first.md)'s development boundary. The remote mirror
and source-to-mirror mapping have not been implemented.

Alternative: host exact ZIPs with a custom Composer repository. Consumers must
declare that repository in their application root; this is not public Packagist
publication, and dependency repositories do not propagate. It changes the
installation/channel contract and needs its own approved hosting/consumer proof.
See [Composer repositories](https://getcomposer.org/doc/05-repositories.md).
